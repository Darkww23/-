# АНОМАЛИЯ 228 / Anomaly 228

Хоррор-игра для Roblox Studio, основанная на городской легенде о жутком лице на экране старого компьютера.

## Описание

Вы оказываетесь в старой российской квартире. На экране ЭЛТ-монитора появляется жуткое искажённое лицо. Чтобы выжить, вы должны следовать правилам.

### Правила игры:

1. **Правило 1** — Сохраняйте спокойствие. Не задерживайте взгляд на экране.
2. **Правило 2** — Попытайтесь выключить компьютер. Если устройство не реагирует — не паникуйте.
3. **Правило 3** — Если изображение не исчезло, а ваше лицо стало искажённым — как можно быстрее покиньте комнату.
4. **Правило 4** — Попытайтесь выйти из квартиры. Если дверь не открывается — смажьте её раствором. Подождите несколько минут.
5. **Правило 5** — Открыв дверь, вы должны увидеть ваш подъезд. Если вместо подъезда вы видите вашу комнату с включённым компьютером — **НЕ ОБОРАЧИВАЙТЕСЬ**.

## Как открыть в Roblox Studio

1. Скачайте файл `Anomaly228.rbxlx` из этого репозитория
2. Откройте **Roblox Studio**
3. Нажмите **File → Open from File** (Файл → Открыть из файла)
4. Выберите скачанный файл `Anomaly228.rbxlx`
5. Игра откроется в студии — нажмите **Play** для тестирования

## Элементы игры

### Локации
- **Комната** — Старая квартира с ЭЛТ-монитором, кроватью, книжным шкафом
- **Прихожая** — Узкий коридор с входной дверью
- **Подъезд** — Лестничная клетка (видна при хорошей концовке)

### Предметы
- **Монитор** — ЭЛТ-монитор с жутким лицом (нажмите E для взаимодействия)
- **Тряпка** — Лежит в прихожей (подберите для протирки двери)
- **Раствор** — На полке в комнате (подберите для протирки двери)
- **Дверь** — Входная дверь (откройте для побега)

### Концовки
- **Хорошая концовка** (60%) — За дверью подъезд, вы выбрались
- **Плохая концовка** (40%) — За дверью снова ваша комната, аномалия поглотила вас

### Управление
- **WASD** — Движение
- **E** — Взаимодействие с объектами
- **Мышь** — Камера

## Доработка

Для улучшения игры рекомендуется:

1. **Добавить текстуры** — Загрузите текстуры обоев, пола, мебели в Roblox Studio
2. **Добавить звуки** — Замените placeholder звуки на настоящие хоррор-звуки
3. **Добавить лицо** — Загрузите изображение жуткого лица как Decal/Image в Roblox
4. **Настроить освещение** — Подправьте яркость и цвет по вкусу

### Как добавить изображение лица на монитор:
1. В Roblox Studio найдите `Workspace → Apartment → Furniture → Monitor → Screen → SurfaceGui → FaceImage`
2. Загрузите изображение через Game Explorer → Images
3. Скопируйте Asset ID изображения
4. Вставьте ID в свойство `Image` объекта `FaceImage` (формат: `rbxassetid://ЧИСЛОВОЙ_ID`)
