# RPG Dungeon Crawler - Roblox Studio

Комплексная RPG-система для Roblox Studio: процедурная генерация подземелий, боевая система с критами и способностями, AI врагов с конечным автоматом состояний, лут с редкостью предметов, инвентарь, прокачка персонажа и боссы.

## Архитектура системы

```
src/
├── ServerScriptService/          # Серверные скрипты
│   ├── GameManager.lua           # Главный оркестратор всех систем
│   ├── DungeonGenerator.lua      # Процедурная генерация подземелий (BSP)
│   ├── EnemyAI.lua               # AI врагов со state machine
│   ├── CombatSystem.lua          # Боевая система, урон, статус-эффекты
│   ├── LootSystem.lua            # Генерация лута, редкости, выпадение предметов
│   └── PlayerDataManager.lua     # Данные игрока, левелинг, сохранение
│
├── ReplicatedStorage/
│   └── SharedModules/
│       ├── Config.lua            # Конфигурация всех систем
│       └── ItemDatabase.lua      # База данных предметов (оружие, броня, расходники)
│
├── StarterGui/
│   ├── CombatHUD.lua             # HUD: хп/мана/стамина, способности, лог боя
│   └── InventoryUI.lua           # UI инвентаря с экипировкой и тултипами
│
└── StarterPlayerScripts/
    └── MinimapSystem.lua         # Миникарта с рендером подземелья
```

## Возможности

### Процедурная генерация подземелий (BSP)
- Алгоритм Binary Space Partitioning для создания уникальных этажей
- 8-18 комнат на этаж с коридорами (L-образные и петлевые)
- Ловушки (шипы, огонь, яд, стрелы, валуны)
- Сундуки с лутом, факелы, декорации
- Комната босса каждые 3 этажа (начиная с 3-го)
- Портал выхода на следующий этаж

### Боевая система
- Формула урона с митигацией брони: `damage * (1 - defense / (defense + 100))`
- Критические удары с настраиваемым шансом и множителем
- 8 способностей игрока: PowerStrike, Fireball, Whirlwind, HealingSurge, DashStrike, IceBarrier, ThunderClap, ShadowStep
- Статус-эффекты: DoT (яд, ожог), Slow, Drain, Stun
- Спец. эффекты оружия: горение, вампиризм, цепная молния, взрывные стрелы

### AI врагов (конечный автомат)
- 5 состояний: Idle → Patrol → Chase → Attack → Flee
- Pathfinding через PathfindingService
- 5 типов обычных врагов: Skeleton, DarkMage, Golem, Spider, Wraith
- 2 босса: DragonLord (3 фазы, 1500 HP), LichKing (3 фазы, 1200 HP)
- Фазы боссов: изменение скорости, урона, новые способности
- Масштабирование характеристик по этажам

### Лут и инвентарь
- 5 уровней редкости: Common, Uncommon, Rare, Epic, Legendary
- 8 видов оружия, 9 единиц брони, 7 расходников, 4 аксессуара
- Случайная генерация статов с учётом редкости
- Инвентарь на 30 слотов с drag-and-drop экипировкой
- Выпадение золота и предметов из врагов
- Специальные эффекты предметов (ReviveOnDeath, MagicReflect, DoubleJump и т.д.)

### Система прокачки
- 50 уровней с экспоненциальной кривой опыта
- +15 HP, +8 Mana, +5 Stamina, +3 Attack, +2 Defense за уровень
- Разблокировка способностей на уровнях 3, 6, 10, 15, 20, 28, 35
- Автосохранение через DataStoreService каждые 60 секунд
- Регенерация маны (2/с) и стамины (5/с)

### UI
- HUD с полосками HP/Mana/Stamina/XP
- Панель способностей на Q/E/R/T
- Плавающие числа урона с анимацией
- Боевой лог
- Индикаторы баффов
- Полоска здоровья босса
- Инвентарь (Tab) с тултипами
- Миникарта с рендером подземелья, врагов, сундуков и портала

## Установка в Roblox Studio

1. Откройте Roblox Studio и создайте новый Baseplate
2. Скопируйте содержимое файлов в соответствующие сервисы:
   - `ServerScriptService/` → Script/ModuleScript в ServerScriptService
   - `ReplicatedStorage/SharedModules/` → ModuleScript в ReplicatedStorage/SharedModules
   - `StarterGui/` → LocalScript внутри ScreenGui в StarterGui
   - `StarterPlayerScripts/` → LocalScript в StarterPlayerScripts
3. `GameManager.lua` — обычный **Script** (не ModuleScript), остальные серверные файлы — **ModuleScript**
4. Клиентские файлы (`CombatHUD`, `InventoryUI`, `MinimapSystem`) — **LocalScript**
5. Запустите тест — подземелье сгенерируется автоматически!

## Управление

| Клавиша | Действие |
|---------|----------|
| ЛКМ | Атака ближайшего врага |
| Q | Способность 1 |
| E | Способность 2 |
| R | Способность 3 |
| T | Способность 4 |
| Tab | Открыть/закрыть инвентарь |

## ObbyGenerator

Отдельный скрипт `ObbyGenerator.lua` для автоматической генерации **обби** (obstacle course / полосы препятствий).

**Возможности:**
- Автоматическая генерация уровня с настраиваемым количеством этапов
- Движущиеся платформы (жёлтые), вращающиеся платформы (оранжевые)
- Kill-блоки (лава), чекпоинты каждые 3 этапа, монетки
- Leaderstats (Stage + Coins), финишная платформа с трофеем
- Декоративные парящие кристаллы

**Установка:** вставьте `ObbyGenerator.lua` как Script в ServerScriptService и нажмите Play.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `STAGE_COUNT` | 15 | Количество этапов |
| `PLATFORM_WIDTH` | 8 | Ширина платформы |
| `GAP_MIN` / `GAP_MAX` | 8 / 14 | Расстояние между платформами |
| `HEIGHT_VARIATION` | 6 | Максимальное изменение высоты |
| `KILL_BRICK_CHANCE` | 0.3 | Шанс появления kill-блока |
| `MOVING_CHANCE` | 0.35 | Шанс движущейся платформы |
| `SPINNING_CHANCE` | 0.15 | Шанс вращающейся платформы |
| `COIN_CHANCE` | 0.5 | Шанс появления монетки |
