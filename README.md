# NPC Controller для Roblox Studio

Скрипт для NPC (куба), который патрулирует заданную зону и начинает следовать за игроком при клике.

## Поведение

- **Патрулирование** — NPC ходит по случайным точкам внутри зоны, останавливаясь на пару секунд в каждой
- **Следование** — при клике на NPC он начинает идти за игроком
- **Переключение** — повторный клик возвращает NPC обратно в режим патрулирования

## Как установить

### 1. Создай NPC

1. В Roblox Studio вставь **Part** (Insert → Part → Block)
2. Назови её как хочешь (например `NPC`)
3. Настрой размер и цвет куба

### 2. Добавь скрипт

1. Правый клик по NPC → **Insert Object** → **Script**
2. Открой скрипт и вставь содержимое файла `src/NPCController.lua`

### 3. Создай зону патрулирования

1. Вставь ещё одну **Part** в Workspace
2. Назови её **PatrolZone** (важно — имя должно совпадать)
3. Сделай её нужного размера — это будет область, по которой ходит NPC
4. Установи свойства:
   - `Anchored` = true
   - `CanCollide` = false
   - `Transparency` = 1 (чтобы была невидимой)

> Если не создашь PatrolZone, скрипт автоматически создаст зону 50x50 вокруг NPC.

### 4. Запусти игру

Нажми **Play** и кликни на куб — он начнёт за тобой ходить! Кликни ещё раз — вернётся к патрулированию.

## Настройки

В начале скрипта можно изменить параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `PATROL_SPEED` | 16 | Скорость при патрулировании |
| `FOLLOW_SPEED` | 24 | Скорость при следовании |
| `PATROL_WAIT_TIME` | 2 | Пауза в точке патрулирования (сек) |
| `FOLLOW_STOP_DISTANCE` | 5 | Минимальная дистанция до игрока |
| `PATROL_ZONE_NAME` | "PatrolZone" | Имя объекта-зоны в Workspace |
| `NPC_HEIGHT` | 3 | Высота NPC над землёй |
