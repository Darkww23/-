# NPC Controller для Roblox Studio

NPC-гуманоид (куб) с плавным движением: патрулирует зону и следует за игроком при клике.

## Поведение

- **Патрулирование** — NPC плавно ходит по случайным точкам внутри зоны через `Humanoid:MoveTo()`
- **Следование** — при клике на NPC он начинает идти за игроком
- **Переключение** — повторный клик возвращает NPC обратно в режим патрулирования
- **Humanoid** — NPC использует Humanoid для реалистичной ходьбы (без дёрганий)

## Как установить

### Способ 1: Быстрая установка (автоматическая сборка)

1. В Roblox Studio вставь **Part** (Insert → Part → Block) — это будет тело NPC
2. Настрой размер и цвет куба
3. Правый клик по Part → **Insert Object** → **Script**
4. Вставь содержимое файла `src/NPCController.lua`
5. Скрипт **автоматически** создаст Model с Humanoid вокруг Part

### Способ 2: Ручная настройка

1. Создай **Model** в Workspace, назови `NPC`
2. Внутрь модели добавь **Part** (куб) и назови `HumanoidRootPart`
3. Внутрь модели добавь **Humanoid** (Insert Object → Humanoid)
4. Внутрь модели добавь **Script** и вставь код из `src/NPCController.lua`

Итоговая структура:
```
NPC (Model)
  ├── HumanoidRootPart (Part — тело/куб)
  ├── Humanoid
  ├── ClickDetector (создаётся автоматически)
  └── Script (этот скрипт)
```

### Зона патрулирования

1. Вставь ещё одну **Part** в Workspace
2. Назови её **PatrolZone** (важно — имя должно совпадать)
3. Сделай её нужного размера — это будет область, по которой ходит NPC
4. Установи свойства:
   - `Anchored` = true
   - `CanCollide` = false
   - `Transparency` = 1 (чтобы была невидимой)

> Если не создашь PatrolZone, скрипт автоматически создаст зону 50x50 вокруг NPC.

### Запусти игру

Нажми **Play** и кликни на куб — он плавно пойдёт за тобой! Кликни ещё раз — вернётся к патрулированию.

## Настройки

В начале скрипта можно изменить параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `PATROL_SPEED` | 12 | Скорость при патрулировании |
| `FOLLOW_SPEED` | 20 | Скорость при следовании |
| `PATROL_WAIT_TIME` | 2 | Пауза в точке патрулирования (сек) |
| `FOLLOW_STOP_DISTANCE` | 5 | Минимальная дистанция до игрока |
| `PATROL_ZONE_NAME` | "PatrolZone" | Имя объекта-зоны в Workspace |
| `MOVE_TO_TIMEOUT` | 8 | Таймаут MoveTo, чтобы NPC не застревал |

## Что изменилось по сравнению с простой версией

- Используется **Humanoid** — NPC двигается плавно, как персонаж игрока
- Движение через `Humanoid:MoveTo()` вместо прямого изменения `CFrame`
- NPC не `Anchored` — физика и гравитация работают корректно
- Автоматическая сборка модели если скрипт добавлен в обычную Part
- Обработка выхода игрока из игры
